    objectType Discovery¶

    Discovery metadata mapped to OCI labels/annotations

    name type mult description
    imageTitle ivoa:string Human-readable title (schema field: title)
    description ivoa:string Human-readable description (1..255 chars)
    source ivoa:anyURI Source code URL
    url ivoa:anyURI optional Project URL
    documentation ivoa:anyURI optional Documentation URL
    version ivoa:string Packaged software version
    revision ivoa:string optional Source control revision; default unknown
    created ivoa:datetime optional Metadata processing timestamp (UTC)
    authors tool.Author 0 or more Responsible people/organization
    licenses ivoa:string SPDX license expression
    keywords ivoa:string 0 or more Discovery/search keywords
    domain ivoa:string 1 or more Scientific domains; default astronomy; min_length=1
    kind ivoa:string 1 or more One of notebook
